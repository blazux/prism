# Appearance and layout

Open **Settings → Appearance** to change Prism’s theme, typography and window
layout. You can use a built-in theme or create and save your own palette.

## Choose a theme

Select **Active theme**, or use the theme dropdown in the header. **Prism Dark**
and **Prism Light** provide plain backgrounds. For a more restrained decorative
background, choose **Graphite** with pinstripes, **Slate** with a subtle chart,
**Paper** with a still background, or **Boardroom** with an office skyline.

The other themes include **Midnight** with stars, **Nord** with snow,
**Solarized Dark** with bokeh, **Rosé Pine** with petals, **Tech** with a network,
**Cyberpunk** with a circuit, **Matrix**, and **Synthwave** with a grid. For themes
with animation, use **Animated background** to set its intensity from 0 to 100%.
A value of 0 turns the animation off.

## Create a custom theme

Choose an **Accent color**, a dark or light **Mode**, and a **Harmony**:
monochromatic, analogous, complementary or triadic. Prism generates the palette
from these choices. Open **Edit every color** to adjust individual colors.

Click **Preview**, enter a **Name**, then click **Save & apply** to use the theme.
You can export a custom theme as JSON with **Export** and load it again with
**Import**.

## Adjust typography and density

Use **Interface font** to choose the system font or one of the listed families:
Inter, Helvetica, Serif, Monospace or Rounded. You can also enter a custom
font-family for a font installed on your computer.

Adjust **UI scale** to change the interface size. **Density** controls spacing,
with compact, comfortable and spacious options.

## Arrange the chat and widget windows

Choose **Chat panel side** to place the chat on the left or right. Enable
**open chat on load** if you want it visible when Prism opens.

With **Window snapping**, dragging or resizing a widget window aligns it with
nearby windows and displays guides. Hold **Alt** to bypass snapping temporarily.
Use **Tidy up** in the dock or command palette to arrange all open windows in a
uniform grid.

## Open the command palette

Press **Ctrl+K** to open the command palette. From there, you can switch to an
app, workspace or terminal, or run an action such as **Tidy up**.
