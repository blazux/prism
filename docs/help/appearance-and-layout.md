# Appearance and layout

Open **Settings → Appearance** to change Prism’s theme, typography and window
layout. You can use a built-in theme or create and save your own palette.

## Choose a theme

Choose a preview card, use **Current theme**, or use the theme dropdown in the
header. Changes apply immediately. The gallery groups the palettes by atmosphere:

- **Essentials**: Prism, Prism Dark and Prism Light. Prism shows a glass prism
  separating a white beam into a gently moving spectrum.
- **Focus & work**: Graphite, Slate, Paper, Boardroom, Ink and Spruce. These use
  still backgrounds, with neutral, navy, ivory or sage surfaces.
- **Color & atmosphere**: Midnight, Nord, Solarized Dark, Rosé Pine, Espresso
  and Dune. Choose deep blue, arctic gray, plum, coffee or warm sand.
- **Geek & retro**: Tech, Cyberpunk, Matrix, Synthwave, Dracula, Amber Terminal,
  Arcade and Bubblegum. Their backgrounds show a drifting constellation,
  circuitry, falling code, a neon landscape, a moonlit castle, an amber terminal,
  a pixel shooter or iridescent bubbles.
- **Your themes**: palettes you have saved in this browser.

Some backgrounds include animated details. **Animated background** adjusts their
intensity from 0 to 100%; 0 turns the effects off. Animations pause while the page
is hidden. With reduced motion enabled in your system or browser, animated
backgrounds become still. Theme changes also reach Prism's apps and widgets that
use its theme tokens.

Prism, Midnight, Rosé Pine, Tech, Cyberpunk, Matrix, Synthwave, Dracula, Amber
Terminal and Arcade show the background through the chat, between the message cards.
The header and message composer are opaque. Other themes use an opaque panel.
A system or browser preference for reduced transparency or higher contrast
restores an opaque chat background.

## Create a custom theme

Open **Create a custom theme**. Use **Use current theme** to copy its palette,
or choose an **Accent color**, a dark or light **Mode**, and a **Harmony**:
monochromatic, analogous, complementary or triadic. Prism generates the palette
from these choices. Open **Edit every color** to adjust individual colors.

Click **Preview**, enter a **Name**, then click **Save & apply** to use the theme.
Leaving Appearance without applying a preview restores the saved theme.
You can export a custom theme as JSON with **Export** and load it again with
**Import**.

## Adjust typography and density

Use **Interface font** to choose the system font or one of the listed families:
Inter, Helvetica, Serif, Monospace or Rounded. You can also enter a custom
font-family for a font installed on your computer.

Adjust **UI scale** to change the interface size. **Density** controls spacing,
with compact, comfortable and spacious options.

## Arrange the chat and widget windows

Choose **Chat panel side** to place the chat on the left or right. Enable
**open chat on load** if you want it visible when Prism opens.

With **Window snapping**, dragging or resizing a widget window aligns it with
nearby windows and displays guides. Hold **Alt** to bypass snapping temporarily.
Use **Tidy up** in the dock or command palette to arrange all open windows in a
uniform grid.

## Emoji shortcuts in chat

Chat messages display familiar emoticons and named shortcuts as emoji after
sending. This also works in Rooms and the Telephony supervision chat.

| Shortcut | Emoji |
| --- | --- |
| `:)` or `:-)` | 🙂 |
| `:D` or `:-D` | 😃 |
| `;)` | 😉 |
| `:P` | 😛 |
| `:'(` | 😢 |
| `<3`, `:heart:` or `:coeur:` | ❤️ |
| `:thumbsup:` or `:+1:` | 👍 |
| `:thumbsdown:` or `:-1:` | 👎 |
| `:clap:` or `:bravo:` | 👏 |
| `:thinking:` | 🤔 |
| `:joy:` or `:rire:` | 😂 |
| `:tada:` | 🎉 |

Separate shortcuts from surrounding words. Code, links and email addresses
keep their literal text. You can also insert emoji with the smiley button;
hover over an emoji to see its available named shortcuts.

## Open the command palette

Press **Ctrl+K** to open the command palette. From there, you can switch to an
app, workspace or terminal, or run an action such as **Tidy up**.
