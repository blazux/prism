# Appearance & layout

All in **Settings → Appearance**. Defaults are deliberately understated; there's
plenty of depth if you want it.

## Theme
- Pick a theme, or set an **accent colour** and let Prism derive a matching
  palette. Light and Dark are plain; the other themes (cyberpunk, synthwave,
  matrix, nord, rose-pine, solarized, tech, midnight) each get a fitting
  **animated canvas background**. The animation intensity is adjustable, and can
  be turned off.

## Typography & density
- **Interface font**: System default, or Inter / Helvetica / Serif / Monospace /
  Rounded, or a custom font-family for any font installed on your machine.
- **UI scale** and **density** (compact / comfortable / spacious).

## Layout
- **Chat panel side** (left or right) and **open chat on load**.
- **Window snapping**: dragging or resizing widget windows snaps to other windows
  and shows alignment guides; hold Alt to bypass.
- **Tidy up**: arranges all open windows into a uniform grid in one click (dock
  button, or the command palette).

## Command palette
Press **Ctrl+K** for a quick switcher: jump to apps, workspaces, the terminal,
and actions like Tidy up.
