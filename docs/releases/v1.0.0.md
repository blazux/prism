# Prism 1.0.0

> Draft release notes — prepared before publication.

Prism is a self-hosted workspace where an assistant can operate your apps,
build reusable tools and dashboards, and automate work. The 1.0 scope covers
personal installations and trusted teams, with local models or your chosen
AI providers. Shared mode is not public, hostile-tenant isolation.

## Changes since 0.8.2

- **More reliable conversations.** In the open page, chat keeps unsent text
  and attachments until the server acknowledges them. Reconnecting checks
  the existing request instead of automatically starting it again. Interrupted replies retain
  their partial text and a visible error; incomplete tool calls are not executed.
- **History and memory you can inspect.** Load older messages in pages,
  correct saved facts and skills, and review a conversation's summary from
  the chat header. Browsing the archive does not change the model's active context.
- **Work you can follow.** Activity shows current tasks and recorded actions.
  From Telegram, ask about progress in your workspaces and the Rooms your
  account can access.
- **Consistent settings.** Personal and group configuration keep their proper
  scope across workspace changes. MCP connections follow the installation in
  personal mode and the group in shared mode. Save feedback is clearer, with
  edits retained in the agent and workspace forms on failure. Activity's
  filters remain accessible on small screens.
- **Reusable tools.** Custom Python tools share consistent registration and
  execution contracts. Deterministic custom tools remain usable without a
  configured chat model. Repeated identical calls warn the agent before a
  continuing cycle stops the turn.
- **Messaging improvements.** Teams bots connect to a group's shared agent.
  Telegram supports image input and file replies. Saved chat attachments
  retain their image previews.
- **Policy and maintenance fixes.** Tool and model restrictions apply
  consistently across supported entry points. Group deliveries retain their
  configured destination. Runtime and library dependencies are updated.

## Before upgrading

Finish or stop active tasks before restarting; interrupted tasks are not
automatically replayed.

Back up PostgreSQL, workspace files, the `server-private` volume and your
deployment configuration. Preserve the existing encryption key: a database
backup without its key cannot restore encrypted credentials. Custom deployments
must also preserve the location selected by `SECRET_KEY_PATH`.

Keep your existing volumes and deployment mode. Do not enable `MULTI_USER`
as part of an ordinary upgrade.

Review **Settings → Tools**. Widgets and Scheduled jobs each combine several
actions. An older disabled action keeps its combined tool off until you choose
to enable it.

See [Upgrading a running Prism](../UPGRADING.md) for upgrade and rollback
requirements.
