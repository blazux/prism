# Prism 1.1.0

Prism 1.1 adds durable mail and note workflows, a clearer activity view,
integrated PrismVox settings, and security fixes for widgets, authentication
and model connections.

## Security fixes

- Generated widgets and applications run on a separate browser origin from the
  dashboard. Direct dashboard administration remains unavailable from that
  content origin; tools retain the viewer's existing permissions.
- Administrative names are rendered as data instead of JavaScript event code.
  Group administrators see activity only from Rooms they can access.
- Login and signup require POST before processing credentials. Invalid methods
  cannot bypass login throttling.
- Widget credentials remain separate between installations on different ports.
  Proxied services do not receive Prism's login or widget cookies.
- Anthropic, OpenAI-compatible and Ollama clients refuse redirects to another
  origin, keeping API credentials and conversation bodies at the configured
  endpoint. Same-origin path redirects continue to work.
- Workspace runtimes and dependencies are updated, including Node 26, Python
  3.12 and patched image, networking and notebook packages. NVIDIA builds keep
  their supported CUDA/PyTorch stack.

## Features and improvements since 1.0

- **Mail:** persistent drafts, attachments and Prism-managed mail rules.
- **Notes:** linked Markdown pages, revision history, conflict handling, trash
  and recovery.
- **Activity:** a shared view of agent work with progress, tool events and
  links back to the corresponding conversation.
- **AI connections:** simpler provider settings, native prompt caching and
  optional tool discovery for Anthropic and OpenAI. Availability depends on the
  selected provider and model; compatible gateways keep their standard tools.
- **Telephony:** PrismVox configuration in Prism's settings and a Telephony app
  for traffic, call logs and outbound calls, in personal and shared modes.
  An installation without PrismVox does not display a telephony usage error.
- **Everyday use:** improved themes, emoticon shortcuts, file editing,
  attachment previews, reconnect handling and conversation navigation.
- **Installation:** a simplified Compose setup and native AMD64/ARM64 image
  builds.

## Before upgrading

Read the [1.1 upgrade guide](https://github.com/blazux/prism/blob/v1.1.0/docs/UPGRADING.md#upgrading-to-11).
Update the Compose configuration together with the images. Direct HTTP
installations expose a second browser port. HTTPS installations require a
separate widget hostname and proxy route.

Finish active tasks, back up PostgreSQL, workspace files, the server-private
volume and deployment configuration, and preserve your existing encryption key.
Keep the same installation mode and custom mounts. Reload open pages after
startup; back up any browser-only widget data before changing origins.

The release publishes `blazux/prism:v1.1.0` and
`blazux/prism-workspace:v1.1.0` for AMD64 and ARM64 and promotes both to
`latest`. GPU execution workspaces are rebuilt locally.
